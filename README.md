# 🚀 JavaScript for Software Development

> A complete hands-on JavaScript learning journey focused on building real-world software instead of just learning syntax.

## 📌 About

This repository contains my JavaScript learning journey with a focus on practical software development concepts.

Instead of only learning loops and basic syntax, this repository covers how JavaScript is actually used in modern web applications, including:

- DOM Manipulation
- API Integration
- Async Programming
- Search & Filter Logic
- CRUD Operations
- Authentication Basics
- Local Storage
- Real-world Mini Projects
